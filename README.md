# 🎨 رسم و تخمين - Saudi Skribbl.io

لعبة الرسم والتخمين السعودية - نسخة عربية من Skribbl.io

## 🌟 المميزات

- **رسم تفاعلي**: استخدم الفرشاة والألوان المختلفة للرسم
- **كلمات عربية**: قاعدة بيانات شاملة من الكلمات العربية
- **متعدد اللاعبين**: العب مع الأصدقاء في الوقت الفعلي
- **دردشة**: تواصل مع اللاعبين الآخرين أثناء اللعب
- **تصميم سعودي**: واجهة مستخدم جميلة مستوحاة من الثقافة السعودية
- **أدوات رسم متقدمة**: فرشاة، ممحاة، ألوان متعددة، وأحجام مختلفة

## 🚀 كيفية التشغيل

### المتطلبات
- Node.js (الإصدار 14 أو أحدث)
- npm أو yarn

### خطوات التشغيل

1. **تثبيت المتطلبات**:
   ```bash
   npm install
   ```

2. **تشغيل الخادم**:
   ```bash
   npm start
   ```

3. **فتح اللعبة**:
   - افتح المتصفح واذهب إلى: `http://localhost:3000`
   - أو استخدم: `http://127.0.0.1:3000`

## 🎮 كيفية اللعب

### إنشاء غرفة
1. اضغط على "إنشاء غرفة"
2. أدخل اسمك
3. احصل على كود الغرفة وشاركه مع الأصدقاء

### الانضمام لغرفة
1. اضغط على "انضمام لغرفة"
2. أدخل كود الغرفة واسمك
3. انتظر بدء اللعبة

### اللعب
1. **الرسم**: استخدم أدوات الرسم لرسم الكلمة المطلوبة
2. **التخمين**: اكتب تخمينك في مربع النص
3. **النقاط**: احصل على 10 نقاط للتخمين الصحيح
4. **الدردشة**: تواصل مع اللاعبين الآخرين

## 🛠️ الأدوات المتاحة

### أدوات الرسم
- **🖌️ فرشاة**: للرسم العادي
- **🧽 ممحاة**: لمسح أجزاء من الرسم
- **🗑️ مسح الكل**: لمسح الرسم بالكامل

### الألوان
- أسود، أحمر، أزرق، أخضر، أصفر
- برتقالي، بنفسجي، وردي، بني
- ألوان إضافية للتنويع

### أحجام الفرشاة
- من 1 إلى 20 بكسل
- تحكم سلس في الحجم

## 🔧 التطوير

### هيكل المشروع
```
├── index.html          # الصفحة الرئيسية
├── styles.css          # ملف التنسيقات
├── script.js           # منطق اللعبة
```

### التقنيات المستخدمة
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)

- **Fonts**: Cairo (Google Fonts)
